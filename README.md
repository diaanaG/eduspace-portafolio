# EduSpace — Portafolio de Diseño UX / HCI

Aplicación móvil colaborativa de apuntes, explicaciones paso a paso y comunidad de estudio universitario para estudiantes de la Facultad de Ingeniería de la Universidad Nacional de Itapúa (FIUNI).

## Organización del repositorio

- `index.html`: Portafolio completo con el proceso de diseño centrado en el usuario (Secciones 1 a 6 para la entrega parcial; Secciones 7 a 9 en la entrega final).
- `css/estilos.css`: Hojas de estilo basadas en el Sistema de Diseño de EduSpace (cumpliendo contraste WCAG 2.1 AA).
- `img/`: Capturas optimizadas de personas, mapas de viaje, bocetos Crazy 8s, evolución de prototipos y sistema de diseño.
- `anexos/`: Documentos PDF completos de respaldo de cada etapa del proyecto.
